# Final QA — DarendeDijital Ultra Revizyon

Tarih: 11.08.2026

## Geçen kontroller

- 25 HTML dosyası parse edildi.
- 21 indexlenebilir canonical URL ile sitemap URL kümesi eşleştirildi.
- 21 sitemap URL’sinin tamamı yerel HTTP sunucusunda `200` döndürdü.
- Yerel `href`, `src`, `srcset`, CSS ve JS referanslarında kırık dosya bulunmadı.
- Tüm indexlenebilir sayfalarda tek H1 bulundu.
- Duplicate HTML `id` bulunmadı.
- JSON-LD bloklarının tamamı JSON parse kontrolünden geçti.
- `assets/js/app.js` Node syntax check geçti.
- CSS açılış/kapanış süslü parantez sayısı eşit.
- Eski .com alan adı referansı paket genelinde `0`.
- `CNAME`, `robots.txt`, sitemap, canonical, `og:url`, schema ve `config.js` `darendedijital.com` ile uyumlu.
- 404 sayfası `noindex,follow`; GitHub Pages alt URL’lerinde bozulmaması için root-relative varlık yolları kullanıyor.
- İletişim formu backend endpoint yokken boş hata vermek yerine doğrulanmış alanlardan e-posta taslağı oluşturacak şekilde çalışıyor.

- `prefers-reduced-motion` erişilebilirlik tercihi korunuyor.
