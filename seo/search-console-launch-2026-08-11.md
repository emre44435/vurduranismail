# Google Search Console Yayın Kontrolü

## Yayına almadan önce
- GitHub Pages custom domain: `darendedijital.com`
- CNAME: `darendedijital.com`
- robots.txt sitemap: `https://darendedijital.com/sitemap.xml`
- Tüm canonical / og:url değerleri: `https://darendedijital.com/...`

## Search Console
1. `darendedijital.com` için **Domain property** oluştur.
2. Google’ın verdiği DNS TXT kaydını alan adı DNS yönetimine ekle.
3. Doğrulama sonrası Sitemaps bölümüne `sitemap.xml` gönder.
4. Önce ana sayfa, `/malatya-dijital-ajans/`, `/darende-web-tasarim/`, `/darende-seo/` ve `/darende-google-ads/` URL’lerini URL Inspection ile kontrol et.
5. Canlı URL testi sonrası gerekiyorsa indeksleme iste.
6. İlk haftalarda Pages, Sitemaps, Core Web Vitals ve Search performance raporlarını izle.

> Google doğrulama TXT değeri kullanıcı hesabına özeldir; sahte `google-site-verification` değeri koda eklenmemiştir.
